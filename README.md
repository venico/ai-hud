# AI-Hud

DeepSeek Harness（dsh）的****AI-Hud**：一个可拖拽的桌面浮层，用红条显示上下文占用、蓝条显示余额，并在你设置的阈值自动压缩历史。

## 安装

桌面版：**设置 → 插件 → 添加插件**，填入：

```
https://github.com/venico/ai-hud
```

安装后它会作为一个插件包出现在插件列表里，带官方开关（**启停即时生效，无需重启**）。

## 功能

**红条 · 上下文**
- 实时显示 `当前占用 / 模型真实窗口`（窗口自动从会话路由读取，读不到时用配置里的备用值）
- 四档告警：<65% 正常 / ≥65% 关注（自动压缩） / ≥80% 高压 / ≥90% 临界（强制压缩 + 闪烁）
- 压缩会把较老的历史总结成一条摘要，保留最近 16%

**蓝条 · 余额**
- 显示剩余金额与预算比例
- **总预算默认跟随官网真实余额**：直连 `GET /user/balance` 读取账户余额，每 60 秒同步一次；
  因此蓝条的「剩余」始终等于账户真实余额，两次同步之间还会随消费继续递减
- 关掉「跟随官网真实余额」后，可手填固定预算

**详细用量**（默认折叠）
- 会话消耗 / 总消耗 / 已花金额 / 压缩次数与节省
- 当前计价时段与单价（官方空闲/高峰双档）

**计价**
- 官方 2026 起的空闲/高峰双档价格（元 / 每 1M tokens），按**每次调用发生时刻**的档位计费
- 空闲时段：北京时间 00:30–08:30，其余为高峰
- 默认值取 `deepseek-flash` 一列：未命中输入 1/2、缓存命中 0.02/0.04、输出 4/8

## 界面

- 浮动层默认在右下角，可拖动、可缩放，位置与大小会记住
- 右上角 **⋮** 菜单：压缩 / 设置 / 收起 / 重置
- **收起**后变成一个小药丸（`● 游戏模式 ¥余额`），点一下即可展开
- 皮肤自动跟随 dsh 主题（浅色/深色），状态色各备一套

## 配置

⋮ → 设置，可调：预算（或跟随官网）、六个价格、上下文窗口、压缩阈值、API Key。
每项都有悬停说明。配置与用量存在 dsh profile 目录的 `.game-mode-state.json`。

> API Key 只保存在本机状态文件里，用于读取官网余额；它不会出现在本仓库中。

## 结构

这是一个标准的 dsh **bundle 包 + 双面插件**：

- `cordis.patch.yml` — bundle 的 patch 层，声明插件注册行（由 `dsh.bundle.patch` 指向）
- `package.json` — `dsh.bundle.patch`（bundle 声明）与 `dsh.client`（Web 客户端声明）
- `lib/index.js` — host 半：记账、压缩、持久化，并在 `webServer` 上注册 `/game-mode` 前缀路由
- `lib/client.js` — 客户端半：`shell.overlay` 浮层，直接 `fetch('/game-mode/<method>')`

## 卸载

插件页面里移除该插件，或从 profile 的 `dsh.profile.bundles` 中删掉 `ai-hud`。
